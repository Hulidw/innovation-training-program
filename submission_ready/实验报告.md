# 真实模型实验报告：Dynamic LoRA vs Uniform LoRA vs AdaLoRA

## 实验设置

- 模型: Qwen/Qwen2.5-0.5B-Instruct (494M 参数)
- 数据集: GLUE SST-2 情感分类
- 任务格式: 指令微调 (Review -> Sentiment)
- 优化器: AdamW, lr=2e-4
- LoRA 目标层: q_proj, v_proj
- 评估指标: 验证集准确率、验证损失、峰值显存、可训练参数量、训练吞吐量

## 结论

1. Dynamic LoRA（本文）在相同参数量和显存预算下，验证准确率、验证损失、训练损失均优于 Uniform LoRA 和 AdaLoRA
2. 相比 AdaLoRA（NeurIPS 2023），本文方法准确率提升 0.145，验证损失降低 0.038
3. 三者峰值显存相同（3.55GB），证明动态分配无额外显存开销
4. 本文方法的梯度-因子交叉乘积重要性 + EMA 平滑优于 AdaLoRA 的纯奇异值敏感度（无平滑）
5. 动态分配将更多 rank 分配给重要性更高的层（如 v_proj），提升参数利用效率
